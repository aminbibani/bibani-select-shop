BIBANI SELECT – ÖFFENTLICHE KUNDEN-WEB-APP

Dies ist eine neue, unabhängige Version. Die alte chatgpt.site-Seite und die private Standzentrale werden nicht verändert.

VERÖFFENTLICHEN (GitHub Pages):
1. Auf github.com ein NEUES öffentliches Repository anlegen, z.B. bibani-select-shop-neu.
2. Alle Dateien aus diesem Ordner in die WURZEL des neuen Repositories hochladen (nicht die ZIP-Datei).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Danach wird die neue Seite unter https://DEIN-NAME.github.io/bibani-select-shop-neu/ erreichbar.
5. iPhone: In Safari öffnen > Teilen > Zum Home-Bildschirm.

SHOPIFY:
Shop-Adresse ist in index.html und app.js hinterlegt: https://bibaniselect.myshopify.com
Die App versucht, öffentliche Produkte über /products.json zu laden. Das kann je nach Shopify-Einstellungen/CORS scheitern. Dann erscheint ein sicherer Shop-Link als Fallback. Die vollständige automatische Synchronisierung ist daher noch NICHT garantiert.
Die Zahlung erfolgt immer direkt bei Shopify. Keine eigenen Zahlungsdaten werden gespeichert.
Die Merkliste speichert Produkte lokal auf dem jeweiligen Gerät.

Vor Veröffentlichung prüfen: Shopify-Adresse erreichbar, Produkte und Preise richtig, Shop-Impressum/Datenschutz vorhanden.
